## 用户反馈和处理

帧号从 0 开始，用户说的“第 N 帧”是这里的 N-1。

| 反馈 | 处理 |
|---|---|
| 待机没有手部动作，应拆成站立待机和上弹 | 拆成 0-3 和 4-9。0-3 是一张露出双手的画，加裙摆摆动和胸口起伏。4-9 逐帧按原版重画 |
| 站姿收手前四帧一样，其实是拍手 | 10-13 逐帧重画 |
| 抬腿转身前两帧差太远，第三帧手枪有缝 | 26-27 重画；28 保留，手做贴合 |
| 枪和手有缝，应统一处理 | 所有持枪帧统一做手部贴合，见下 |
| 走路幅度小，看不出摆臂和脚步 | 68-75 逐帧重画，有步幅、摆臂和裙摆摆动 |
| 滑铲两帧静止；向右滑时头发应向左飘 | 82-83 重画，头发和裙摆向左飘，两帧的飘动不同，身体不动 |
| 受击站起第四帧、收势第一帧小一号 | 每段内统一大小；99-102、140-142 也重画了 |

对照页加了“原版 + 左轮”一栏，可以直接比较手和枪。

## 动作表

H3 跟不上每帧都不同的快动作，手尤其容易丢。这次改成一次生图画一张表：参考图是按格排好的原版姿势，模型把每格重画成人物。同一张表里人物和配色一致，每张约 $0.2。表的定义在 `design/claude_gunner/pose_sheets.json`。

除反馈提到的动作外，复核时发现下面几段也有问题，一并重画：

- 32-39 展臂转身：v01 多为背影，手臂被头发挡住。
- 52-59 弓步突刺：58-59 的轮廓跳变。
- 64-67 持枪交叉：手的位置差得远。
- 76-81 跑步：v01 的枪压在头发上，看不到手。
- 21：比下一段小，姿势也不准。

共画了 8 张表，覆盖 0-13、21、26-27、32-39、52-59、64-83、99-102、140-142，其中 0-3 共用一张画。其余帧仍是 v01 的 H3 视频。

## 手枪贴合

枪是游戏的独立图层，按原版的手画，所以手不在原版位置就有缝。`scripts/claude_gunner_hands.py` 对每个持枪帧做三步：

1. 找原版的手：皮肤层里露在外面、贴着枪的像素。
2. 找人物的手，沿人物轮廓弯曲手臂移到原版位置。越靠近手移动越大，躯干、头和脚基本不动。
3. 把原版的手部像素转成统一调色板，画在最上面，握法和原版完全一样。

这是统一的自动处理，不针对某一把枪。其他枪种也用同样的帧序号，但这次只检查了左轮。

## 大小统一

- 每段内用同一个缩放。
- 22-25、60-63、119-139 比新画的段高约 7%，缩到相同的身高比例。
- 重复抽到同一视频帧的连续帧，改用相邻帧，保留头发和裙子的自然微动。

## 校验数据

- 覆盖率平均 0.906，最差帧 0.741（在 108-112 高踢段）。缩小 3 段和重画都会让这个数变化，不能和 v01 的 0.914 直接比较。
- 脚底与原版的偏差：中位数 0，九成帧不超过 1px，最大 19px（腾空帧）。
- 比原版高很多的只剩第 103 帧（1.55 倍）。

## 已知不足

- 67 帧持枪帧共 81 只手。贴合前手离原版位置的中位数是 6.9px，最大 14.9px。其中 7 只手的自动检测没找到肤色，改用“人物最靠近枪的部位”，这几帧看过放大图没有问题。
- 枪和身体的遮挡顺序仍是模拟（枪在最上层），实际以游戏为准。
- 新画的帧线条更干净，和保留的 H3 帧风格略有差别，切段时可能看得出来。
- 飞踢第 103 帧仍偏高，第 118 帧倒立时裙子很大。这两处没有被反馈提到，没有改。
- 动作分段仍是我按轮廓分的，不是游戏 ANI 定义。
