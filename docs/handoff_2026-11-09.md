### 操作上的坑

- Python 用 ComfyUI 的环境：`D:/VideoStudio/comfyUI/install/ComfyUI/ComfyUI/.venv/Scripts/python.exe`（有 PIL、numpy、scipy、av）。
- Windows 控制台按 GBK 显示，Python 打印的中文会乱码。要看中文就写到文件里，再用 Read 读；数据本身没坏。
- 改了工作台的 Python 代码要重启服务，还要结束旧的渲染进程（`worker.py`，空闲一小时才会自己退出）。PowerShell：`Get-CimInstance Win32_Process -Filter "Name='python.exe'" | ? CommandLine -like '*workbench*' | % { Stop-Process -Id $_.ProcessId -Force }`。
- `avatar_data.dll` 默认去运行程序（python.exe）所在目录找数据，`scripts/avatar_data.py` 已经设了环境变量 `DNF_AVATAR_DATA_DLL` 指向 `tools/downloads/dnf_avatar_studio_1.8.1/`。
- 资源库的导入顺序：先 `scan`，再 `avatar_data.py export`（数据有变时才需要），再 `dnf_kb.py import`。
- COLG 搜索连续两次就会被限流（“提示信息”页），要间隔开。COLG 需要登录，用户已在内置浏览器里登录；curl 访问会被拒绝。
- 用户常把下载放在项目根目录。`.gitignore` 已排除 `*.zip`、`*.downloading`、`*.baiduyun.*`，`git add -A` 前仍要看一眼 `git status`。
- 用 Python 的 `Path.write_text` 改文件会把换行变成 CRLF，不影响运行。通过 heredoc 生成的 Python 代码里，`b"\0"` 曾变成一个真正的 NUL 字节，导致文件编译失败。含转义字符的代码要用 Edit 工具或单独的脚本文件写，不要嵌在 heredoc 字符串里。
