# 女鬼剑 · GPT 龙娘 v03

把女鬼剑（`swordman/atequipment`）的全部时装换成 GPT 龙娘的整体绘制精灵。保留原版 246 帧的动作和帧序号，武器按太刀检查贴合。形象（母版 `master_b_0`）和 v02 相同，v03 重画了全部动作。

文件：`output/gpt_dragon_slayer_v03/A_GPTDragon_FSlayer_v03.NPK`。卸载：退出游戏后移走这一个文件。v02 和 v03 不能同时放在游戏目录里，`install` 会把 v02 移出。

状态：离线校验通过，**尚未在游戏内验证**。

GPT 龙娘是民间二创，不是 OpenAI 官方形象。三视图由用户提供，原作者和授权未核实，请仅自用。

帧号从 0 开始，用户说的“第 N 帧”是这里的 N-1。配置在 `design/gpt_dragon_slayer_v03/`，由 `make_sheets.py` 和 `motions.json` 生成。

## 为什么有 v03

2026-11-08 按后来积累的经验重审 v02，发现：

| 问题 | v02 | v03 的做法 |
|---|---|---|
| 去拖影删掉原版的鞋 | 84 帧参考图少一只脚，模型照着少画；12 帧脚底对到脚踝，人被抬高 16–22px | 用修好的去拖影重新导出合成帧（`materials/gpt_dragon_slayer_source_v03`），接触表逐帧有脚 |
| 手和刀错位 | 只有 3 张修复表开了握点圆点 | 全部 31 张表开 `mark_grips`；6 帧握点误判（落在大腿、刀尖）改成手动握点 |
| 待机扭曲 | 12 段用旧的 `phase`，全身摆，脚底每帧变动约 470 像素 | 不用 `phase`。待机照原版 `moving` 的结果只动胸口和肩，腰以下不变 |
| 走路头顶上下跳 | 按脚底对齐，头顶在 4px 内跳动 | `anchor: head`，头顶和原版逐帧一致 |
| 大小不一 | 9 张表偏差超过 6% | `sizes` 量出 7 张表的系数，写进 `clip_scales.json`，复查后全部在 6% 以内 |
| 重复帧各画各的 | 0 帧复用 | `reuse.json` 复用 13 帧（如 196–200 = 218–222） |

## 手和太刀

- 圆点是根据原版握点画在参考图上的，模型把拳头画在点上。
- 第一轮全量后，11 帧拳头离刀柄超过工具能拉的范围（85–87、121、159、164、168、181、190、226、227），用两张修复表重画；121、164、190 举得不够高，又用第三张修复表重画。
- 余下 `final` 报告：手太远 3 帧（216–218，都是复用 191、195、196 的画面，看过手在刀柄附近）；拉伸超过 12px 的 14 帧，最大 17.6px（第 159 帧）。
- 第 190 帧拳头在刀柄末端外侧约十几像素，原版的拳头也盖住刀柄末端，没有再重画。
- 太刀的黑色护手原来和黑手套融在一起，压在白裙上很显眼，这是武器图层本身，改不了。

## 第一轮审核后的修改

用户在审核页标了 9 个动作（`review.json`），帧号按用户的编号：

| 意见 | 做法 |
|---|---|
| 待机 1–4、叉腰站 10–13、战斗站姿 147–150、背刀站 233–236：脸是不动的 | 微动只从下巴以下（身高 0.21 处）开始，脸的像素变化为 0 |
| 待机抬手 5–9：原版有五指握拳；第二次审核：原版这几帧全身不动，只动手、头和头发 | 待机 1–9 帧改用同一张画（表 `idle_hold`，由 `idle_hand_edit.py` 合成）：以第 1 帧的画为底，请模型只改前手和头（一次修改调用），本地只把上半身和前手贴回底图，这一张表的帧共用一个位置（`hold`）。腿、裙子、尾巴在 1–9 帧逐像素不变；第 7 帧握拳只换手 |
| 挥臂平举 128：原版抬的是另一只手；132 没握到刀柄 | 修复表 `repair_d` 重画 127–128、132 |
| 跑步 152–159：不稳 | 改按头对齐（`anchor: head`，`anchor_px: 48`，因为头顶全是角和飘起的头发）。第二行三格画小了，`frame_scales.json` 放大；腿画得偏短，下半身拉伸 5–6px，脚落回地面 |
| 回身高踢 231–232、终结 245–246：被裁切、偏大 | 修复表 `repair_e` 留足四周空白重画，再按 `frame_scales.json` 缩回 |
| 终结 244：握刀不对 | 同上重画；244 和 245 原版几乎一样，两帧用同一格 |
| 背刀站：握刀的手被遮挡，不需要贴刀 | 这 4 帧不做手部贴合（`hand_overrides.json` 的 `ignore`） |
| 叉腰站：剑应该被裙子挡住 | **未修**，见下方“已知不足” |

修复表的大小和原表不同，`sizes` 复查后用 `frame_scales.json` 统一到 6% 以内。

## 校验数据

- NPK 回读校验通过，其他骨架（222 帧）的路径留在包外，保持官方外观。
- 脚底与原版：中位数 0，九成帧不超过 1px，最大 5px。
- 覆盖率平均 0.925，最低 0.684（第 241–245 帧终结动作，翅膀和裙子张开）。
- 明显高于原版的只有第 46 帧（1.42 倍，抬膝时翅膀和裙摆张开）。
- 完全相同的相邻帧只有 7、8，复用第 6 帧，原版这三帧本来就几乎一样。

## 已知不足

- 未实机验证。武器和身体的遮挡顺序是模拟的（武器画在最上层），实际以游戏为准。
- 刀被裙子挡住：游戏把刀画在人物上面，原版靠在刀图层里按腿的形状挖洞来表现“被腿挡住”。新版人物换了，刀上还是原版腿形的缺口，所以刀会一段一段地浮在裙子上（如叉腰站）。要让裙子挡住刀，只能把改过的刀图层一起打进补丁：太刀有 644 个文件（约 32MB），另外还有 9 种武器，每种都要按龙娘的轮廓重新挖洞。这件事等用户决定。
- 只检查了太刀，其他武器帧序号相同但没有逐帧看。
- 走路按头对齐后，第 19–22 帧鞋底比原版低 4–5px（她画得比原版略高），可能看起来脚稍微陷进地面。
- 跑步第 155、157、158 帧的下半身拉长了 5–6px，换来头稳、脚落地。
- 拉伸超过 12px 的 14 帧放大看过一部分，没有全部逐帧确认。
- 我看了静态帧板和数据，没有看过连续播放，请在审核页或游戏里看一遍。
- 人物比原版宽很多，大动作时遮挡的范围更大。
