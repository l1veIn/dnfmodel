# 大肥鱼女法师 · 正常比例版 v05

2026 年 11 月 5 日。正常头身比，服装按设定图还原女仆装。与大头版 v03、华丽大头版 v04 覆盖相同路径，只能装一套。

## 分层方案能不能做正常比例

能。素体本来就是正常身材，v03 的大头只是当时的选择。v05 把头换回原版大小（约 25px 高），其余沿用同一套合成器，全部 174 帧的动作与原版手绘帧一致。

真正的限制是分辨率：人物约 100px 高，眼睛只有 3–4 个像素。这个尺寸下“精致”靠干净的轮廓和配色，不是靠细节数量。

## 与 v03 的差别

| 部位 | 做法 |
| --- | --- |
| 头 | 新绘 6 张（3/4 三种表情、受击、背面、正面），鹅蛋脸、细长眼，缩放 0.85；其余表情借用最接近的一张 |
| 袖子 | 原版条纹合并成纯色深蓝 |
| 腿 | 白色长筒袜（从鞋向上连通搜索，手不受影响） |
| 鞋 | 淡化鞋带，靠近玛丽珍鞋，但轮廓仍是原版靴子 |
| 裙 | 下摆加一层白色荷叶边；围裙加宽到 30px |
| 发、尾 | 换用更干净的后发，长度 60px；鲸尾缩到 0.52 |

## 成本与验证

- 本版只调用 1 次 native（`heads_n1`），约 $0.2。
- 离线校验：174 帧从 NPK 解码后与渲染 PNG 一致；路径与透明载荷沿用 v02。
- **尚未在游戏内验证。**

## 还没还原的地方

- 设定图是露肩泡泡袖加高跟玛丽珍鞋。袖子和靴子的轮廓来自原版手绘帧，只能改颜色，改形状要逐帧重画。
- 束腰的金扣、长筒袜的小蝴蝶结在这个尺寸放不下。
- 表情只有 6 张，比 v03 少，部分帧共用。

## H3 路线的状态

新流程已写好：用 v05 的帧作动作参考（姿态和服装一开始就是对的），按轮廓匹配逐帧选帧，比较柔和与硬边两种缩小方式（`scripts/fatfish_h3_repaint.py`、`scripts/process_h3_repaint.py`）。**还没有产出结果。** 首次试跑被内存保护中止：H3 峰值约需 13.2 GiB 提交内存，当时可用不够。

## 重建

```bash
cd scripts
python fatfish_normal.py
python release_fatfish_normal_v05.py
```

切换已安装版本（需先退出游戏）：

```bash
python scripts/switch_fatfish.py normal
```
