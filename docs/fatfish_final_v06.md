# 大肥鱼女法师 · 普通版 v06

整体绘制的普通比例版本，不走分层。分层的 v03、v04、v05 按用户的判断都算大头版，v06 是用户要求的“旧 H3 那样，但更好看”的版本。

文件：`output/Fatfish_Final_v06/A_Fatfish_FMage_Final_v06.NPK`。切换：`python scripts/switch_fatfish.py final`（需先退出游戏）。

状态：离线校验通过，尚未在游戏内验证。

## 旧 H3 的问题和本版的处理

| 旧 H3 的问题 | 本版处理 |
|---|---|
| 灰、软、无轮廓，金色和脸都糊了 | 保留线条的缩小、调色、1px 描边、全局共用色板 |
| 按时间抽帧，姿势常常对不上 | 按轮廓匹配选帧，排除头发和尾巴的影响 |
| 个别动作严重错位，如鞭挞最差帧覆盖率 0.6% | 每段拟合缩放和位置，全片覆盖率 0.773 → 0.82，最差帧升到 0.58 |
| 头发过大遮身体，尾巴细 | 新母版：头发限制在身后，尾巴短而贴腿 |
| 人物在视频里只有约 275px | 每段单独取方形窗口，人物约 400px |

## 体型适配（这一版最重要的发现）

从游戏 skin 包实测站姿素体，不含头发：

| 职业 | 身高 | 头高 | 约合头身 |
|---|---|---|---|
| 女法师 | 92px | 15px | 6.1 |
| 女鬼剑 | 112px | 15px | 7.5 |
| 女枪手 | 117px | 15px | 7.8 |
| 女格斗 | 110px | 14px | 7.9 |
| 女圣职 | 114px | 15px | 7.6 |

各职业的头几乎一样大，女法师只是身体短了约两成。头发、耳朵和头饰再一叠加，就容易显得头大。

把母版和原版素体归一化到同一高度后，头高和裙摆位置其实都接近，问题不在头身比，而在体量：约 95px 高时腿细成线，尾巴又长又扁地横着伸出去，浅蓝头发也看不见了。所以新母版 `parts/raw/fit_b_0.png` 没有放大头，只改了这些：

- 头发更丰满，下半段有大片浅蓝渐变
- 尾巴变短，贴腿下垂
- 腿略微加粗，鞋改成低跟
- 海军蓝调亮，缩小后不发黑

中间一张 `fit_a_0.png` 按“加粗”的方向改过了头，头高约 20%、裙摆到 77%，变成了大头比例，因此弃用。

## 生成和后处理

- MiniMax H3 Ref2VA 本地运行，原版合成帧作为动作参考，每段 124 帧，512×512。
- 25 段里 19 段用第 2 轮种子，6 段用第 3 轮并加强提示词（禁止魔法特效，抬腿必须是腿，手臂露在头发前）。跳跃平A也试过第 3 轮，但站得太直、比原版高约 20px，所以换回第 2 轮。
- `scripts/fatfish_final_fix.py` 负责最后一步：脚底对齐原版、循环段统一缩放、借帧、共用色板渲染。

手工处理的帧：

| 帧 | 处理 | 原因 |
|---|---|---|
| 26、27、76、173 | 借 22、23、84、170 | 模型在此处仍站着，这些帧与原版姿势几乎相同，轮廓相似度 0.986-1.0 |
| 109 | 借 110 | 模型仍是起手站姿，没有相近帧，是妥协方案 |
| 56、57 | 改用视频第 50 帧 | H3 在这段画了魔法环，第 50 帧已基本淡去 |

## 已知不足

- 战斗跑（18-21）：原版是双脚离地前倾的姿势，本版是真实跑步姿势，未做脚底对齐。
- 落花掌（67-69）：抬腿的位置被尾巴占了，看起来像单脚站着摆尾。
- 跳跃平A（89、90）和召唤（42-44）：手臂被头发遮挡，转身时是背影。
- 覆盖率是轮廓数值，不代表好看；是否好看以游戏内观感为准。
