# 龙娘 buff v03 · 前景透视与连续月牙

本版是助手误读用户意图后的历史方案，不作为当前设计方向。用户澄清原v02龙型边框和飞镜月牙是对的，只需完整龙头前置、其余框后置，并补足月牙跨镜中间帧；按 [v04](dragon_buff_v04.md) 修正，不能继续沿v03胸前大龙/原地月牙形成方向推进。

本版处理用户对 v02 的两条反馈：“龙跟人的透视关系有点怪，龙在前没问题”“月牙刃的入场也很怪，应该做成连续帧”。保留龙在前、人物在后，重画近正面三分之四视角的龙头与完整颈部：口鼻近大，颈从左下出画，人物脸在右上，利用真实遮挡和窄暗紫接触阴影分开体积。不再将同一条龙拆成身体在后、局部头在前，也不对龙挖人脸窗口。

月牙采用新画的 3×4 动作表，共 12 格独立形态，依次为小核、短尖、延长弧刃、峰值、断尾、碎光消散。原表实际 774×2032，每格 258×508，使用同一个整格变换放到 470×668 画布；映射至第 5–16 帧（0起）。不逐格裁 alpha 包围盒、居中或改变大小，不靠同一完整 C 图大幅移动/旋转制造连续感。独立源阶段检查能精确重建全部12格，RGBA差0；12格图像及轮廓均各自不同。

人物沿用既有身份、固定构图、局部衣发微动和真半闭/闭眼插片。19帧、470×668、15fps、透明、无声。前五帧是合法半透明入场，不能为了旧工具“每帧必须接近不透明”的假设加入亮脸或白点；编码应按实际源帧和解码帧的 alpha 范围及误差检查。

素材、精确提示词和 SHA 为 `output/dragon_buff_v03/generation_record.json`；选定布局 `layouts/layout01`、选定动画 `drafts/draft01`、12格提取记录 `fx_reviews/cells01/fx_extraction.json` 均在同输出目录。配置 `design/gpt_dragon_slayer_v03/buff_v03.json`；构建入口 `scripts/build_dragon_buff_v03.py`。标准输出为 `output/dragon_buff_v03/preview/`；独立技术报告为 `output/validation/dragon_buff_v03_qa/`。
