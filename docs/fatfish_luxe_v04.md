# 大肥鱼女法师 · 鲸歌女王华丽大头版 v04

2026 年 11 月 5 日。大头比例，与 [大头版 v03](fatfish_native_doll_v03.md) 并存的第二套外观，两者覆盖相同路径，只能装一套。

这是原创设计，借鉴的是 DNF 高级时装的华丽表现手法（夸张轮廓、层叠布料、金饰、动态特效），没有复制任何现成时装。

## 设计

| 元素 | 做法 |
| --- | --- |
| 配色 | 珍珠白配金，蓝宝石与海水色点缀，和深蓝长发拉开对比 |
| 头 | 金丝冠配蓝宝石与白蕾丝，耳鳍金饰与珍珠；12 种表情和朝向；比大头版略小，仍是大头比例 |
| 礼裙 | 沿用原版裙摆的手绘明暗，按半径分为珍珠白、金线、海洋渐变内层（星点闪烁）、金边、蕾丝；下加海洋与蕾丝两层裙撑放大轮廓 |
| 纹章前摆 | 女仆围裙升级版，白盾配手点金鲸 |
| 上身 | 袖子珍珠白配金色细条纹，金边袖口，金翼蓝宝石领饰 |
| 腿 | 从鞋向上连通搜索出腿部，染成白丝袜，手不受影响 |
| 拖裙 | 物理链驱动，贴地堆叠；金边在最终轮廓上重新描绘 |
| 鲸尾 | 深蓝加金环珍珠，海水色发光尾鳍，叠在拖裙上形成对比 |
| 光翼 | 两片半透明鲸鳍翼，金脉不透明，随动作扇动；贴地姿态时收拢 |
| 光环与粒子 | 淡金光环，星光与气泡环绕，整周期运动，循环动作不跳 |

## 这个尺寸学到的

华丽感靠大色块和干净的金边，不靠堆细节。第一版把画好的金色卷草直接缩小，拖裙糊成了锡箔纸，束腰成了一团金块；去掉内部金纹、只留边线后才好看。

## 成本与验证

- native 调用 5 次：概念图、两张头部、两张部件，约 $0.97。提示词与原图在 `output/Fatfish_Luxe_v04/parts/`。
- 概念设定图：`output/Fatfish_Luxe_v04/parts/raw/concept_0.png`。
- 离线校验：174 帧从 NPK 解码后与渲染 PNG 逐像素一致；路径与透明载荷沿用 v02。
- **尚未在游戏内验证。** 半透明光翼和更大的帧范围都需要实机确认。

## 已知取舍

- 光翼、拖裙让角色轮廓比原版大很多，遮挡敌人或队友的视线会多一些。
- 拖裙和头发按手工标注的动作片段模拟。同一帧被多个技能复用时，姿态只对应所在片段。
- 光环、粒子画在人物贴图里，不是游戏特效，不发光，也会被人物遮挡规则一起处理。
- 手持武器沿用原版坐标，未实测与光翼、拖裙的前后遮挡。
