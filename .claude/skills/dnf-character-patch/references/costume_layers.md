# 指定装扮的分层制作

适用于穿指定帽子、上衣才换外观的补丁。原版身体动作和持握已经符合设定时，可把主要工作放在像素外观和接缝上。若身体结构、肢体动作或武器持法要大改，走[整身替换制作顺序](../SKILL.md#整身替换制作顺序)。

## 选底和制作小样

1. **先确认目标组合。** 用试衣间和官方 IMG 看帽、上衣、皮肤、持武器层的实际堆叠。记录装备 ID、资源路径、原点、画布、帧数与绘制深度。同一套装的展示名、装备条目和实际 IMG 数量通常不同。挑一套能对照接缝的原版组合，并检查换上其他目标帽或上衣后的组合。多个目标的发布映射见[定向覆盖与发布](targeted_release.md#按装备路径明确范围)。
2. **从领口完整的身体出发。** 要替换或去掉围巾时，优先比较同骨架、同动作、无围巾的原生时装。用无围巾底衣的衣领、肩胯和四肢轮廓确定姿态。保留原版合成作动作对照，避免从遮住领口的衣服删掉若干像素后靠补色猜形。
3. **锁定全帧同一坐标系。** 分层 PNG、对照原图、握点标记和局部修图共用原画布及零基 IMG 槽号。利于叠帧检查，也便于封包时按 alpha 非空范围裁小图，写回其绝对偏移和原画布。透明帧、link 和调色板按实际目标验收。
4. **先看代表帧。** 从普通待机、战斗待机、走跑各选一小段，再抽一个双手或袖口经过脸前的动作。提交固定取景的原版对照与游戏尺寸循环。通过后再扩展全量，在动作前后、遮挡转折、背面和闭眼处增加取样。

## 头、身体与围巾

- **身体随原版动作。** 在每帧原生衣片上描线、局部改色并保留已有的手脚轮廓、支撑脚、近远肢体关系和原武器握位。腹纹、领口和脚掌按可见区域绘制。身体正背可参考原套装纽扣、肩领走向与肢体遮挡，核对相邻帧的转面。正面腹纹在侧身时变窄或被袖口遮住，背面按其实际可见部分绘制。
- **头先按姿势和看向匹配。** 逐帧记录脸朝向、俯仰、歪头、实际可见的近远眼和眼内视线。首选原版最终合成里可见的近眼位置对齐。两眼或瞳孔无法辨认时，按可见下颌、领口接点或后颈定位，并在表中标明使用的锚点与遮挡。保留头套前后片的相对位置。先锁眼位，再看下巴是否顶住袖子及领口是否露缝。源图脸向错误时修正绘制或改瞳孔像素，平移只处理位置偏差。
- **围巾是独立的制作层。** 需要围巾时，可从合适原生服装逐帧取得围巾及飘带，再核对新领口的位置和前后遮挡。先画完整身体和腹纹，再叠围巾。把围巾放回对应前后衣片，最终按游戏读取的上衣 IMG 烘入。工作文件里的围巾层可以单独编辑，运行时跟随的是实际装备槽和路径。
- **按实际堆叠导出。** 原版女法示例使用 `coat_d → cap_b → coat_a → cap_a → coat_c` 从后到前合成，短杖的后层与前层参与审核。该案例的帽与上衣有 174 个槽位、500×500 画布。其他职业或不同装备组以实盘层序为准。分层上衣的袖、领、帽沿可以跨越角色的视觉前后，逐帧看叠层结果。

## 逐帧修正

1. 在现有审核台加载原版、候选和实际武器。对正在修的帧记动作、零基 IMG 槽、目标层及判断依据。先按帧查看眼位和接缝，再把同动作连播看头部位移是否形成不必要的跳动。
2. 用品红底检查脖颈的异常透底、接缝破洞和孤立边缘，用深浅底看描边及颜色。先确认是本来存在的空位、被遮挡、偏位还是缺像素。有可信基准时对两片头套作一致的整数平移。边缘缺口逐像素补，眼睛或附件方向错误时局部重画。检查相邻帧和透明通道，避免把原本的袖间空隙填实。
3. 已接入分层编辑的项目可在工作台取色、改单像素和逐帧平移。其他项目用像素编辑器或逐帧修订记录保存修改。增量修复先保存底稿，记录具体的层、槽和像素变化。读取并保留已保存的手动修订，批量偏移只应用于确实需要的帧。回读头套位移后的边缘，排除被画布裁切的像素。对仅改色的修复，校验 alpha 一致以及目标范围外 RGBA 一致。
4. 封包前按同一套顺序叠出包含手动修订的最终素材，比较实际审核画面和成包回读的同坐标合成。至少试原搭配、一个不同颜色或来源的目标变体，以及只换帽或只换上衣。全套独立性、已覆盖的装备代码和共享路径须写清楚。完整出包检查见[定向覆盖与发布](targeted_release.md)和[验收清单](acceptance.md)。

## Doro 和小咕嘎的例子

这两套女法装扮使用胖萌熊猫上衣的干净领口作为共同底衣。对照使用经典像素头和雪人上衣的原版动作，把新外观写回已核实的像素头、雪人和胖萌熊猫时装路径。

| 角色 | 定版做法 | 检查重点 |
|---|---|---|
| Doro | 奶白身体以三档阴影收束，保留清晰的肩袖和身体交界描边，领口保持无围巾。头套经大小小样确认后按原版眼位逐帧处理。 | 检查身体轮廓和画风在大动作仍连贯。先试了向下 3 像素的调整，再按袖口和眼位逐帧取 0–3 像素并保留手调结果。这个数值来自当时的头套与衣领组合。 |
| 小咕嘎 | 在原衣片上画炭灰身体、奶白肚皮和黄色脚掌。身体独立画完后叠红围巾，并把围巾烘到对应衣片。 | 保住炭灰小手和黑色裤脚。肚皮按身体朝向与袖片遮挡变化，领口与围巾边缘无残余阴影。待机四槽曾有脚背露黑，按原始轮廓补齐黄脚掌和暖色过渡，保留裤脚投下的合理深边。 |

重点复核的女法动作包括走路 `000–009`、待机 `010–013`、战斗待机 `014–017`、跑步 `018–021` 与碎霸 `035–041`。碎霸看双手随动作一同向身后挥，以及收势时后手被头挡住。只修图时继续用原版持杖层比对握点和遮挡。

## 已替代的尝试

| 尝试 | 本案例采用的做法 |
|---|---|
| 对适合原生动作的雪人大头造型逐帧整身重画，再切头和身 | 先用干净领口的原生身体逐帧改衣片，头套独立定位。整身重画仍适用于身形或动作本身要改的项目。 |
| 从有围巾的雪人套硬扣原围巾，再猜被遮住的衣领 | 选择无围巾的同骨架底衣，需要围巾时从可靠来源分离并重新叠放。 |
| 把白色雪人全身按四阶一键换成黑白，或用同色硬刷脚掌 | 先按原衣片与动作区分小手、肚皮、脚掌和裤脚，再逐区用角色的调色与真实边缘处理。 |
| 给头套一刀切统一偏移，或拉伸手脚来贴上标记 | 以逐帧原版锚点和原生四肢定位，使用小幅刚性位移、像素修正或局部重画，检查相邻帧和遮挡。 |
