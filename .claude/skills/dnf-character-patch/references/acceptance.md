# 验收清单

每一条都来自用户对真实补丁的反馈。给用户看之前逐项查过。

## 比例

| 查什么 | 怎么查 | 不对怎么办 |
|---|---|---|
| 正常比例，不是大头 | `small` 对比原版。用户把头占比偏大的版本都叫“大头版”，很介意 | 改母版提示词里的头身比，重画母版 |
| 身材和职业相符 | `measure`。女法师矮两成但头一样大，高挑角色放不进去 | 先改角色体型，不要硬塞 |
| 全程大小一致 | `sizes` 按面积比各表，`stats` 看相邻段的身高比（手臂画低、姿势舒展都会让身高比失真，以面积为准）。同一姿势在相邻段的大小要一样，比如 22 和 26 | 按 `sizes` 的系数写 `clip_scales.json`（切表时自动生效），视频段跑 `match-sizes` |
| 同段内不忽大忽小 | `board` 看段的首尾帧 | 工具已按段统一缩放；姿势本身太大就重画 |

## 动作

| 查什么 | 用户原话 | 做法 |
|---|---|---|
| 快动作每帧都不同，跟原版一致 | “细节上每一帧都不一样，是一个拍手的动作” | 动作表逐帧画，不用 H3 |
| 手部动作不丢 | “手部动作缺失” | 动作表提示词写清每格手的位置；头发不能盖住手臂 |
| 停留帧有微动，不完全静止 | “避免角色完全静止” | 待机用 `micro`，幅度和部位照原版；滑铲这类表里两格的飘动要不同；视频段跑 `unfreeze`。`stats` 的相同帧列表应为空，但原版就重复的帧可以相同 |
| 停留帧的脸不动 | “原版的脸部4帧像素是不变的”（女鬼剑待机、叉腰站、战斗站姿、背刀站） | `micro` 的 `lift`、`shear` 要从下巴以下开始（量成品帧，下巴约在身高 0.18，头上有角时更低），下巴以上写 0。复核：头部那几行的像素变化应为 0 |
| 微动不能变成扭曲 | “连起来看就像是正在扭曲一样”“脚尖处是不动的”“下半身是不动的，动的只有部分头发和手臂” | 先用 `moving` 统计原版，不动的部位像素要完全不变。复核：对比帧间差异，按高度分段统计，脚尖和下半身应为 0 |
| 走路上半身稳 | “默认走路跟原版比显得特别不稳定”“原版的躯干到头部的位置在这十帧里几乎没变” | 给走路段写 `"anchor": "head"`，不用重画。复核：把段内帧叠加成一张图，头应该和原版一样清晰；逐帧比头的位置，应和原版一致 |
| 待机模仿不来就重新设计 | “这四帧可以重新设计一下，总之就是不要让玩家觉得角色是静止的” | 目的是不显得静止，不是逐像素复制。不要让头和裙子反向摆，那样显得扭曲 |
| 待机要放松，不能僵 | “只有呆毛和尾巴动，还是有些太严肃了，不够放松”“简单的把双手改成放身前就行了” | 只动垂挂的东西不够。站姿也要放松，先问用户要什么姿势，别一次改太多。脚不动，身体从脚底起同向轻摇，加呼吸，尾巴和发梢错开节拍，用 `micro` |
| 两只脚都在 | “这个问题后面还出现过多次” | 逐帧数脚。原版合成图少脚时先查全部图层，通常是工具删掉的。新版少脚时先看 `_marked` 图，圆点可能正落在脚上 |
| 人物没有被格子切掉 | “新版切割是不是出问题了？原版是有脚的，新版切掉了，而且人物也大一圈” | `sheet-cut` 会对碰到格子边缘的帧发 WARNING，只是贴边可以不改，真切掉的要重画或复用，并加大 `pad_x`、`pad_y`。提示词写明四周留白 |
| 走路看得出摆臂和步伐 | “幅度太小，看不出手臂摆动和脚步” | 动作表画，提示词写清步幅、摆臂、裙摆跟腿走，靴子从裙下迈出 |
| 头发和裙摆方向对 | “向右滑铲时候头发应该向左飘” | 写提示词前先看原版朝向；精灵默认朝右，向右运动时松散物向左飘 |
| 姿势真的是原版的姿势 | “前两帧也是和原版差距太大” | 不靠覆盖率判断，轮廓对也可能姿势错。逐帧看 `board` |
| 背影段能看到手臂 | 我自查时发现长发盖住手臂和手 | 提示词写头发垂在背后不盖手臂 |
| 尾巴、翅膀这类附件长在身后 | 自查时发现大肥鱼第 98–101 帧尾巴长到了裙子前侧 | 手臂在身后交叉的姿势最容易错。全部帧逐一看附件位置，重画时直接写明附件在图的哪一侧、绝不能出现在哪一侧 |
| 附件的生长位置和姿态自然 | “现在这样像是从腰上长出来的所以不太自然，应该从臀部长出来”“太长太细，应该更短更粗” | 用户说自然比三视图优先时，按用户的改，差异表记为改动。用 `master-edit` 只改这一处 |

## 手和武器

用户：“问题的本质是，原版的手部跟我们补丁的手部位置需要尽可能贴合。”

- 对照页必须有“原版 + 武器”一栏，用户要直接比。
- `hands` 特写里，每只手都要接上武器，没有缝。
- 武器图层在握点处常留缺口，由原版的手盖住。手没到位或画得比原版窄时，法杖会看起来断成几截，还会有短头悬在空中。把所有握杖帧放进一张图，围绕握点裁切后放大一起看（女法师法杖就是这样）。双手握的帧只贴合一只手，另一处缺口盖不住，要告诉用户。
- 拳头差一点够到时，超过 12px 搜索范围会显示 `no hand near`，手不会动。可以用手动指定（`{"23": [[x, y]]}`），但手臂会被拉长，超过约 15px 就重画。
- 看 `final` 最后两行：`too far` 的帧和拉伸超过 12px 的帧都要放大看。差太多说明姿势本身不对，重画比硬拉手臂好。拉伸会把相连的头和脚一起拖歪，日志不会报这个。
- 模型把手画错位置时，文字改不好，用 `mark_grips` 重画。
- `grips <文件> <帧>` 放大看腰部，红圈是握点，手要落在圈里。`hands` 一次放很多手时缩得太小，看不出缝。
- 检查工具有没有拽错手：另一只手被拖向刀柄时，手会和手臂分开，像飘在空中。GPT 龙娘第 14、15 帧中过，所以持刀职业要开 `grip_gap`。
- 太刀的黑色护手在黑手套上看不见，在浅色服装上会很显眼。这是武器图层本身，无法修，要告诉用户。
- 武器图层在原版腿、身体挡住的地方挖了洞（游戏把武器画在人物上面，靠挖洞表现遮挡）。换成长裙、大翅膀的角色后，刀会带着原版腿形的缺口一段一段浮在衣服上（用户：“原版的剑是被双腿遮挡，龙娘是裙子中间应该完全遮挡”）。只换人物修不了，要把按新轮廓重新挖洞的武器图层打进补丁，一种武器就有几百个文件，先问用户。
- 不需要握刀的帧（刀在身前、握刀的手被挡住，如女鬼剑背刀站 232–235）写进 `hand_overrides.json` 的 `ignore`，否则工具会把手拽到刀柄上。
- 没有贴到身上的漂浮手（`graft` 贴了但手臂没到），有就修目标或重画这帧。

## 外观

用户：“做出来的成品手臂上华丽的袖子没了，尾巴变短了翅膀也是，而且颜色变成青色了。”

- 用户选定的设计不主动改。Claude 大小姐的长裙是用户明确要保留的。
- 母版和参考图逐项对比：标志性大轮廓都在，大小相当，没有新增色块。差异表给用户确认过（见 [prompts.md](prompts.md)）。
- `colors`：成品和参考图的色相相差不超过约 10°，没有青色。
- `anim` 生成动图，看大块布料是否在帧间跳动。静态图和轮廓数据都看不出这个。
- 新画和保留的 H3 帧放在一起看，风格差别不能太大。
- 色板统一，由 `final` 完成，不要单独处理某一段。

## 技能道具、人物帧和切入图

用户：“用生图模型按帧拼接动画还是不够稳定，这里是视频模型发挥的地方。”“实际上就是那几个三觉切入图有问题。”“运镜要求其实不是很严格，只要流畅即可。”

- 三觉切入图（`_neo` 5 套）不用生图拼帧。全屏动画要连续播放才看得出问题，帧板和单帧放大都不算验证。
- 运镜不用和官方逐帧一致，看流畅，人物不走样。
- 逐张找官方人物：切入图和特效包里的人物帧容易漏，放大招时会闪回官方形象。
- 道具贴合看 `plan` 和 `cut` 的吻合度，低于约 0.7 的看 `board`。含人物的帧分数本来就低，看图判断。
- 枪口、喷口要和原版大致重合，因为光效位置改不了。
- 看动图里有没有闪：分表画的相邻帧细节可能不同。
- 边缘没有细小横杠和粉色杂边。
- 蓝色光束配橙色机身不搭，配套发光层要一起调色。
- 说清哪些文件男女共用，哪些大招特效本身还是官方颜色。
- NPK 体积和全屏帧的内存占用要报给用户。

## 打包

## 无法离线确认，请用户看

- 武器和身体的遮挡顺序：工程上把武器画在最上层，实际要看游戏。
- 其他武器种类：贴合只检查了配置里那一种，其他种类的帧序号相同。
- 动作分段是看轮廓分的，不是游戏 ANI 定义。
