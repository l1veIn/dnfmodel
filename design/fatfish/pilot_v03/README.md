# 大肥鱼女法师 v03：局部修正、4 帧片段与试装 NPK

本轮范围是修正既有走路、施法、跳跃的手脚偏差，制作 IMG 0–3 四张相邻帧的短片段，并封装一个供用户手动接入游戏的小范围测试包。未制作完整 174 帧动画，也未自动安装进游戏。

- `sequence/0001_canvas.png` 至 `0003_canvas.png`：紧接修正后的 IMG 0 的三个相邻帧。

## 修正方法与证据边界

每张修正请求都有既有大肥鱼动作图、对应原动作灰色参考和站姿造型参考。生成新手脚后，先做全局尺度/方向校正，再对局部关节/鞋底作坐标约束，最后仅合成指定手脚区域。`corrected/*_composite.json` 和 `*_patch_mask.png` 记录变换、掩码及修改像素数。掩码以外的脸、头发、服装和尾巴与原 v02 图逐像素一致。

`qa/corrected_target_pixel_checks.json` 检查实际修正图在目标点附近是否存在相应肤色/鞋子像素。目标点本身是修正时的拟合约束，因此不会把数学上拟合到零的残差当成独立骨骼验证；标点仍有约 1–2 个原生像素的人为估计误差，关节连接和遮挡需结合图像与实机检查。

相邻帧最初以大肥鱼上一帧作编辑底图时，模型沿用了大步姿势。该成功但未选用的候选保存在 `raw/walk_001_0.png`。正式相邻帧改以原动作灰图作编辑底图，大肥鱼上一帧和修正后的造型图仅作外观参考，优先保留原动作的腿部交叉与手脚关系。

四帧中的脸、头饰和头部区域采用同一图像作整数像素平移复用，主动防止脸型和头饰逐帧改变。这是明确的身份锁定处理，不是声称模型独立生成的脸天然完全一致。头部以外的长发、裙摆、尾巴和袖口仍需进行连续性检查。

检查结果：三个修正动作在指定手脚目标附近可找到相应材质像素，最近距离约 0–1.4 个原生像素；它们是约束点附近的像素检查，不是独立骨骼精度。四帧头部区域在按预期平移后逐像素相同。帧间图像仍能看到裙摆、背发和尾巴轮廓变化，因此没有把这段片段标成完整无抖动动画。鞋型与原靴子不同，首帧所选支撑脚标点距可见鞋底像素约 3 像素，其余三帧约为 0；实际接触点、速度与滑步仍需结合客户端判断。

本轮共有 7 个生图/编辑任务（含一个未选用相邻帧候选），任务回执合计 0.266 美元。记录见 `qa/provider_receipts.json`。

## 预览的含义

IMG 0–3 是一小段相邻图像帧，**不是完整步行循环**。工程预览按 140 ms/帧播放，末帧暂停后显示重播提示。原游戏 ANI 的动作组、逐帧时长和世界位移尚未解析认证，不能把该 GIF 当作实机节奏。

接地模拟根据原素材所选支撑脚点平移角色，将该脚点放在固定地面位置，便于观察身体与衣物变化。因此接地预览里的脚点固定是模拟约束，不能据此宣称实机完全没有滑步。实际落地、移动速度、武器遮挡与层级仍由用户在客户端测试。
