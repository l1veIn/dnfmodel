# 女法师 Cosplay 大肥鱼：造型草案 v01

![造型草案](concepts/fatfish_mage_v01.png)

本稿使用内置 image_gen，以用户提供的 fatfish_game 工程内角色图和当前 DNF 女法师动作参考生成。

## 造型提取

- 深蓝到浅蓝的长卷发、卷呆毛、鲸鳍耳饰和浅蓝蝴蝶结。
- 白色女仆头饰、蓝白裙装、白围裙的小鲸鱼纹样、少量金色扣子/蝴蝶结/裙边装饰。
- 白色连裤袜、深蓝玛丽珍鞋、后腰鲸尾。
- 沿用女法师基础身形。将原参考长裙调整为适合动作的膝长裙摆。

## 当前产物的范围

三视角服装设定与两幅像素风格预览，用于讨论轮廓、颜色和标志细节。图中的像素预览不是精确 90px 动作帧，没有与游戏帧坐标逐像素对齐，也没有作为 IMG 导入。所有 174 个帧位仍需在造型收敛后逐帧生产和核验。

后续先制作站立/走动/施法的对齐样帧，核对头身比例、发型轮廓、前后遮挡和鲸尾摆动，再扩展剩余帧位。暂未更改游戏资源。
